# Privacy and Asset Policy

TECHNOseller Portal is intended to be GitHub-ready and public-safe.

## Allowed

- Original UI code created for this project
- Synthetic company, vendor, lead, and marketplace data
- Generated or designed assets that are approved for public use
- Clean derivative assets explicitly provided for this project

## Not Allowed

- Private archive files
- Raw legacy template files
- Personal photos, names, email addresses, or identifying records from private sources
- Third-party copyrighted material without clear permission

## Review Checklist

- Confirm every committed asset is public-safe.
- Confirm screenshots do not reveal private folders, usernames beyond standard local paths, or archive thumbnails.
- Keep source references in documentation descriptive rather than embedding private files.
- Prefer synthetic data for all demos, tests, and screenshots.
